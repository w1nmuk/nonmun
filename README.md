# 📚 딥 서치 논문 리더기 (Deep Search Paper Reader)

arXiv와 Semantic Scholar API를 교차 검증하여, 영향력 있는(인용수가 높은) 논문을 필터링하고 초록을 한국어로 번역해주는 웹 애플리케이션입니다. 

단순 검색을 넘어, 연구자나 학생이 양질의 논문을 빠르게 선별하고 마크다운 문서로 깔끔하게 보관할 수 있도록 돕습니다.

## ✨ 주요 기능
* **스마트 검색:** arXiv 최신/연관 논문 지속 탐색 (Pagination 지원)
* **인용수 필터링:** Semantic Scholar 연동을 통해 기준 인용수 미달 논문 자동 제외
* **자동 번역:** `deep-translator`를 활용한 논문 제목 및 초록 한글 번역 제공
* **결과 저장:** 검색된 우수 논문 리스트를 보기 좋은 마크다운(`.md`) 파일로 자동 생성 및 다운로드
* **사용자 친화적 UI:** Streamlit 기반의 깔끔하고 직관적인 웹 인터페이스 제공

## ⚙️ 설치 방법 (Installation)

1. 프로젝트 저장소를 복제(Clone)하거나 다운로드하여 폴더를 엽니다.
2. 터미널(또는 명령 프롬프트)을 열고 해당 프로젝트 폴더로 이동합니다.
3. 아래 명령어를 입력하여 실행에 필요한 외부 라이브러리를 한 번에 설치합니다.
   ```bash
   pip install -r requirements.txt

   ```
## 🚀 사용법 (Usage)
1. 터미널에 아래 명령어를 입력하여 웹 애플리케이션을 실행합니다.
   ```bash
   streamlit run app.py
   ```
2. 자동으로 브라우저가 열리면 사이드바에서 검색 환경을 설정합니다.
     - 찾을 논문 개수: 최종적으로 화면에 띄울 합격 논문의 수
     - 최소 인용수 기준: 필터링할 최소 인용 횟수
     - 최대 탐색 한계선: 무한 로딩을 방지하기 위해 최대 몇 개까지 논문을 검사할지 제한

3. 중앙 검색창에 찾고자 하는 키워드(예: FPGA routing 또는 NPU architecture)를 입력하고 검색 버튼을 누릅니다.

4. 탐색이 완료되면 화면에서 논문의 요약본을 확인하고, '결과 마크다운(.md) 파일 다운로드' 버튼을 클릭하여 결과물을 저장합니다.

## 📁 프로젝트 구조 (Project Structure)
  - app.py: 웹 브라우저 화면(UI)을 구성하고 사용자와 상호작용하는 메인 실행 파일입니다.

  - arxiv_engine.py: 논문 검색, 인용수 확인, 데이터 정제 및 번역 등 핵심 로직을 전담하는 모듈입니다.

  - requirements.txt: 프로그램 실행에 필요한 외부 패키지(streamlit, deep-translator 등) 목록입니다.
